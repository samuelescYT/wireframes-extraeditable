Recursión en Python

⏱ 15 min · Lección 3 de 5 · En progreso
▶
Ver video explicativo · 8:32
La recursión es cuando una función se llama a sí misma para resolver un problema dividiéndolo en subproblemas más pequeños. El caso base detiene la recursión, y el caso recursivo avanza hacia él.
caso base pila de llamadas memoización backtracking
💡 Pista del profesor: Siempre define el caso base primero. Si tu función no tiene uno, causará un error de pila (stack overflow).

Ejercicio Fibonacci recursivo
Implementa la función fibonacci(n) usando recursión. El sistema validará automáticamente tu solución con casos de prueba.
